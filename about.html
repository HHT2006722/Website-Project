关于我

我是韩宏涛，一个在学动漫插画的普通人。这个网站是我的练习本，不是作品集——里面既有我临摹学习的画，也有我按参考重新画的场景，还有每周记下来的复盘。

我把临摹当作学习方式：先照着原画把结构、光影、配色一遍遍拆开，再试着不看参考重画一遍。这个过程很笨，但每次都能发现自己卡在哪一步。网站上放出来的图，我会在正文里写清楚每张是怎么来的、参考了谁，因为学习别人的东西不丢人，假装是自己画的才丢人。

下一步想把重心从临摹转到原创：先固定一套自己的角色设定，再用同一套场景反复画不同的时间段和天气。这件事急不来，我打算一个月只推进一小步，把过程记在日志里。

我现在在练什么

  • 逆光与剪影：先把光源位置定死，再决定人物哪一侧留高光。练的是「主体和背景不能同明度」这件事。
  • 低饱和背景：把背景的对比度和饱和度一起压下去，主体不画细节也会跳出来；难的是压过头会显脏。
  • 大面积星空：先铺暗色底、再点星点，最后用一条亮的流星把视线从左上引到右下。

这个网站是怎么做的

纯 HTML / CSS / JavaScript，没有框架、没有后台、没有数据库，托管在 GitHub Pages。图片统一导出 480 / 960 / 1600 三档 WebP，用 srcset 让手机只下载最小那档；灯箱用浏览器原生的 <dialog>，焦点管理和 Esc 关闭都不用自己写。

每一步技术选择的「选了什么、放弃了什么、怎么验证的」，都记在仓库的 DECISIONS.md 里；每周的改动记在日志里。

我用的工具

  • Clip Studio Paint（主要用来画线和上色）
  • iPad + Apple Pencil（起稿和外出速写）
  • 一小盒马克笔（手快的时候用）
